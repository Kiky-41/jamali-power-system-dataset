# ⚡ Jamali Power System Dataset v1.0.0
[![DOI](https://zenodo.org/badge/1233957236.svg)](https://doi.org/10.5281/zenodo.20098064)

Initial public release of an operational and generation dataset for the Java–Madura–Bali (Jamali) interconnected power system.

---

## 📊 Overview

This repository provides benchmark operational data for large-scale power system analysis and optimization studies on the Jamali interconnected grid.

The dataset is intended for:

- Economic Dispatch (ED)
- Economic Emission Dispatch (EED)
- Unit Commitment (UC)
- Generation scheduling
- Power system optimization

---

## 📦 Contents

- Generator operational data
- Power plant characteristics
- Capacity and scheduling information
- Benchmark test cases
- Supporting documentation

---

## 🌐 System Coverage

The dataset represents the interconnected power system of Java, Madura, and Bali — the largest electricity network in Indonesia.

---

## ⚙️ Potential Applications

The dataset can be used for studies involving:

- Classical optimization methods
- Metaheuristic algorithms
- Swarm intelligence
- Evolutionary computation
- Constraint-handling optimization
- Power generation scheduling

---

## 🔍 Supported Constraints

Benchmark cases may include:

- Generator capacity limits
- Ramp-rate constraints
- Power balance constraints
- Spinning reserve constraints
